# Studio 故事控制中心

Studio 保留 inkOS 原有的创作入口、书架、会话树、互动影游、系统和工具分区。展开书架中的任一本书后，会在会话列表上方显示“故事控制”入口。

作品内的“故事控制中心”依次提供总览、规格、动态大纲、对标机制、质量审查、正史提交、自动化和发布。

总览的阶段状态来自真实 Spec、报告、HEAD、preflight 和发布记录。规格页展示真实场景、人物议程、隐藏/未知信息、信息承载、互动链和旁白许可；质量页展示语义场景问题、Human Feel 决策、修订状态与完整报告。待批准草稿支持编辑、重新执行全部审查和按正文哈希批准。正史页显示 Commit/投影阻断；发布页要求显式确认交付和发布结果。

故事控制中心复用 Studio 原有 Logo、Sidebar、字体、主题 token、按钮、表单、弹层和状态色。外部平台交互仍通过导出包和日志边界完成。
