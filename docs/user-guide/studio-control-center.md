# Studio 故事控制中心

Studio 按生产职责组织，而不是按第三方原型页面复刻。

- **生产**：项目总览、创建长篇、创作会话。
- **连载作品**：写作入口与故事控制入口。
- **研究与资产**：市场雷达、合法文本/正史导入、文风与题材规则。
- **运行与治理**：自动写作、模型角色、项目策略、诊断和日志。

作品内的“故事控制中心”依次提供总览、规格、动态大纲、对标机制、质量审查、正史提交、自动化和发布。

总览的阶段状态来自真实 Spec、报告、HEAD、preflight 和发布记录。质量页允许接受/拒绝单条 Human Feel 问题并锁定段落；正史页显示 Commit/投影阻断；发布页要求显式确认交付和发布结果。

桌面端使用原创左侧控制轨；窄屏使用底部四项主导航。界面不加载原型字体或 Logo，不复制平台发布页面，外部平台交互仍通过导出包和日志边界完成。
